mongodb://localhost:27017

campusflow

mongodb://localhost:27017/campusflow

Collections:
users
courses

notices
events

campus_requests

Important:
The connection name "CampusFlow Local" is a MongoDB Compass label. It is not a database name.
The backend automatically creates the database/collections on startup and seeds the default admin and sample campus data.
